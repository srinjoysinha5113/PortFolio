## ✨ Features

- **🌀 Interactive Animations:** Powered by `framer-motion` and `GSAP` for fluid transitions and scroll-triggered effects.
- **✨ Advanced UI Components:**
  - `BlurText` & `SpotlightCard` for modern aesthetics.
  - `Particles` background for a deep, immersive feel.
  - `StaggeredMenu` for a unique navigation experience.
- **📱 Fully Responsive:** Adaptive design that looks stunning on mobile, tablet, and desktop.
- **💼 Comprehensive Sections:** Dedicated modules for **Experience**, **Education**, **Projects**, and **Certifications** (including Microsoft & Deloitte simulations).
- **🌑 Dark Mode First:** A sophisticated dark-themed aesthetic using modern CSS variables.
