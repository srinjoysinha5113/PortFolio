   34 ## ✨ Features
   35
   36 - **🌀 Interactive Animations:** Powered by `framer-motion` and `GSAP` for    
      fluid transitions and scroll-triggered effects.
   37 - **✨ Advanced UI Components:**
   38   - `BlurText` & `SpotlightCard` for modern aesthetics.
   39   - `Particles` background for a deep, immersive feel.
   40   - `StaggeredMenu` for a unique navigation experience.
   41 - **📱 Fully Responsive:** Adaptive design that looks stunning on mobile,     
      tablet, and desktop.
   42 - **💼 Comprehensive Sections:** Dedicated modules for **Experience**,        
      **Education**, **Projects**, and **Certifications** (including Microsoft &    
      Deloitte simulations).
   43 - **🌑 Dark Mode First:** A sophisticated dark-themed aesthetic using modern  
      CSS variables.
